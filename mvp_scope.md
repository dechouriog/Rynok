MVP Definition

The MVP will be a web application that allows any registered user to connect
their Metamask wallet, publish their house for sale, and browse properties
published by other users. Buyers will be able to purchase a property directly
in ETH, with the funds held in an escrow smart contract until the transaction
is confirmed, protecting both buyer and seller. The system should make it
possible to list, discover, and buy real estate using cryptocurrency without
requiring traditional payment rails.
