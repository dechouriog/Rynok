5/5 existing tests pass, but overall coverage is honestly low (31.89%
statements). This is expected, not hidden: the visual redesign added several
new screens and components (`Hero`, `Footer`, `HowItWorks`, `PropertyForm`,
`PropertyOwnerActions`, the dashboard/wallet/escrow pages, `lib/api.ts`'s
CRUD functions) without adding matching tests for them yet. `PropertyCard` is
the only component at 100%.

**Priority gaps for the next testing pass, in order of value:**
1. `lib/api.ts` (3.12%) — the CRUD functions (`createProperty`,
   `updateProperty`, `deleteProperty`) have zero test coverage; these are pure
   functions and cheap to test with a mocked `fetch`.
2. `PropertyFilters.tsx` (43.47%) — the price-range and sort dropdown logic
   isn't exercised.
3. `WalletContext.tsx` (36.95%) — only the initial "disconnected" render is
   tested; the `connect()` happy path and error path are not.

## How to reproduce

```bash
cd backend && npm run test:cov
cd frontend && npm run test:cov
```

Both also write an HTML report to `coverage/index.html` in their respective
folders (not committed to the repo — add `coverage/` to `.gitignore` if not
already present) for line-by-line inspection.
